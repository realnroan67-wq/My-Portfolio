# IT Student Portfolio

A responsive, dark editorial-style portfolio inspired by the supplied reference image, reimagined with developer and cybersecurity details.

## Quick start

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Tailwind recompiles automatically when you edit HTML or CSS.

## Production build

```bash
npm run build
```

The build compiles Tailwind and packages the complete static site into `build/`. Deploy the contents of `build/`, preserving folder paths. Vercel reads `vercel.json` to install with `npm ci`, run the build, and serve `build/`.

## Customize

1. Update the three `data-site-name` spans and the page title in `index.html`. Set your email, GitHub, and LinkedIn URLs in `src/main.js` and the matching HTML links for visitors without JavaScript.
2. Open `index.html` to update your biography, skill list, and four project cards.
3. **The first three project cards are clearly marked examples/lab ideas.** Replace them with real work before publishing. Do not claim labs you have not completed.
4. Adjust theme colors in `src/input.css` (`@theme` and custom CSS).
5. Run `npm run build` before deployment.

## Notes

- Built with HTML5, Tailwind CSS v4, and vanilla JavaScript; no JS framework.
- Project artwork is pure HTML/CSS. The profile portrait is `assets/charles-profile.jpg`; include the assets folder when deploying.
- Fonts load from Google Fonts; system fallbacks are defined.
- Responsive navigation, keyboard focus styles, reduced-motion support, and reveal animations are included.
- All profile links use placeholders until you customize them.

## Credentials

The Credentials section links to `assets/linux-unhatched.png` and `assets/linux-unhatched-certificate.pdf`. Keep both assets when deploying. Visitors can view the badge, open or download the certificate, and expand an inline PDF preview.
